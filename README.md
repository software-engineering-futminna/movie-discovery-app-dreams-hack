Description:
A web application that allows users to discover movies, view movie information, search for movies, and save movies to a personal watchlist.


PROBLEM STATEMENT:
1. Finding movies can be difficult with too many choices.
2. Users may forget movies they are interested in
3. Information about movies is scattered across different platforms.



project Objectives:
1. ENABLE USERS TO EXPLORE A WIDE ARRAY OF MOVIES
2. PRESENT VALUABLE AND INFORMATIVE MOVIE DETAILS
3. FACILITATE THE CREATION OF PERSONALIZED WATCHLISTS FOR USERS.
4. OFFER A USER-FRIENDLY AND RESPONSIVE INTERFACE.


system Architecture:
1. Frontend: HTML, CSS, JavaScript (no framework)
2. Data: TMDB API, called directly from the Browser  
3. Localstorage: Browser localStorage for the Watchlist 
4. hosting: GitHub Pages

UI PAGES:
1. Home Page (trending movies)
2. Search Page Genre
3. Browse Page movie Details Page (includes cast information)
4. Watchlist Page

Technologies:
1. HTML
2. CSS
3. JavaScript
4. TMDB API

Features:
1. Movie discovery
2. Movie search
3. Movie details
4. Watchlist
5. Responsive interface
6. display trending Movies 
7. personal Watchlist (Local Storage)
